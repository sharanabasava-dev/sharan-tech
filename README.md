# Sharan-Tech

Modern business website starter built with Next.js + TypeScript.

## 1. Install

```bash
npm install
```

## 2. Run locally

```bash
npm run dev
```

Open:

http://localhost:3000

## 3. Important: update your contact details

Open:

`app/page.tsx`

Find:

```ts
const CONTACT = {
  whatsappNumber: "91XXXXXXXXXX",
  phoneDisplay: "+91 XXXXX XXXXX",
  email: "your-email@example.com",
};
```

Replace those values with your real WhatsApp number and email.

## 4. Useful commands

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## 5. Git

```bash
git init
git add .
git commit -m "Initial Sharan-Tech website"
git branch -M main
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```
